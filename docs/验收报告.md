# Pocket Synth 2.2.0 验证摘要

当前版本包含 Guitar、Expressive、Keys、Drum Machine，支持独立音色选择与四轨 Loop。Keys 的离散音高直接切换，Expressive 保留连续表现；录音保存每个音符的实际音色，回放与当前现场选择分别生效。

## 验证范围

- 本机十项 CTest 通过，覆盖缓存、音色、Loop 操作、鼓机、音频队列、输入、持久化、启动和 WAV 导出。
- 同样十项通过 ASan / UBSan；独立 TSan 缓存、音色和操作体验检查通过。
- 音色行为检查覆盖目录、导航、按键消费、自然衰减、连续性、实际音色保存、缓存身份及迟按八度和半音。
- 四个演奏页、设置页及复杂状态完成画面检查；Mac 应用签名与 CoreAudio 运行验证通过。
- ARM64 在构建电脑交叉编译，R36S 真机行为、命令行、导出、启动及实际 Wayland / PulseAudio 运行验证通过。

## R36S 性能基线

音频配置为 48 kHz、每块 512 帧，处理预算约 10.67 ms。

| 场景 | 平均处理 | 最慢处理 | 超时块 |
| --- | --- | --- | --- |
| 四轨缓存＋现场吉他 | 1.752 ms | 2.518 ms | 0 / 750 |
| 四轨缓存＋八键电钢琴 | 3.772 ms | 4.069 ms | 0 / 750 |
| 四轨缓存＋现场小提琴 | 0.832 ms | 1.300 ms | 0 / 750 |
| 最终键盘版本：八键叠录＋八键现场演奏 | 7.295 ms | 8.310 ms | 0 / 750 |

安装后的实际全屏四轨演示最慢回调为 4.748 ms，队列溢出与超时均为零。最满场景缓存准备约 6–8 秒，属于后台准备阶段，现有伴奏继续回放。这些数据描述已测试设备和场景；其他硬件与固件可按构建文档复测。

## 复测

运行 `scripts/build.sh build-host` 完成本机构建与测试。使用 `-DPS_SANITIZE=ON` 开启 ASan / UBSan；TSan 使用独立构建目录与 `-fsanitize=thread`。性能测量目标为 `performance-measurement`，支持 `full`、`live-keys`、`live-expressive` 和 `live-overdub` 场景。

当前使用方法见[快速上手](快速上手.md)，扩展方法见[音色扩展](音色扩展.md)，工程约束见[工程原则](工程原则.md)。
