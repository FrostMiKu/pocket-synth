# 音色目录与扩展

音色的权威定义位于 `src/sound_catalog.cpp`。每条记录描述稳定 ID、稳定 key、显示名、所属模式、通用发声模型、默认选择和音色参数。目录长度从数据推导；按键切换、设置保存、界面与录音均引用目录。

## 添加同类音色

1. 在目录追加一条 SoundPreset，分配新的稳定 ID 和 key，填写简短显示名及所属模式。
2. 选择现有模型并填写参数。Sustained 提供持续谐波与气息；Struck 提供逐谐波衰减、起音噪声与 FM；Guitar 使用弦模型；DrumKit 使用鼓组。
3. 通过 sound-tests 检查目录身份、默认项、导航、声音、保存和回放，然后试听与运行性能测量。

每种模式有一条明确的默认音色。ID 和 key 表示身份，条目顺序表示切换次序。新增或重排条目时保留既有身份。显示名用于界面，可独立调整。

八个谐波是当前通用模型的单声部计算预算；目录容纳的音色数量由数据决定。新增同模型音色只需追加目录记录。新合成方法可增加独立发声模块和模型类型，继续使用同一套选择、输入、持久化及界面接口。

## 演奏与录音

右＋L2 选择上一个音色，右＋R2 选择下一个；每次按下切换一次。已经按住的音符持有起音时的音色，新起音采用当前选择。Studio 将实际发声音色写入事件，后台缓存依据事件重建，实时选择与已有伴奏分别生效。

设置以稳定 key 保存各模式选择。当前录音格式为 POCKET_LOOP 2，每个事件写入音色 key；应用使用 `settings.cfg.performance`。读取器处理当前格式。应用直接读写当前录音文件。

## 性能与验证

音频线程使用静态目录引用和固定大小的声部状态。谐波通过递推计算，发声循环按实际非零谐波数量执行。预设参数准备在新起音时完成；后台 PCM 缓存继续承担已有轨道回放。音频线程使用的模型保持无文件读取和无动态分配。

`--render-sounds audio.wav` 按目录顺序导出全部旋律音色，便于统一试听。`performance-measurement full`、`live-keys`、`live-expressive` 测量满载缓存加现场演奏。

Keys 的音阶、半音及八度变化直接切到目标音高；弯音与揉音保留。Expressive 保留连续音高表现，音色选择与音高过渡分别处理。
