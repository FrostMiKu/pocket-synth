# Pocket Synth 快速上手

Select 切换乐器，Start 打开或关闭设置，Select＋Start 退出并保存。四种乐器共用四轨 Loop，切换乐器后伴奏继续。

## 音色与快捷操作

先按住右方向键，再按 L2 / R2 选择上一个 / 下一个音色。每次按下切换一次，各乐器分别保存选择。当前音色显示在乐器名称旁；按住右方向键时，底部显示此时的操作。

- Guitar：ACOUSTIC。
- Expressive：FLUTE、VIOLIN。
- Keys：PIANO、ELECTRIC PIANO。
- Drum Machine：ELECTRONIC KIT。

持续中的音符保持起音时的音色，新起音使用新选择。已有 Loop 保持录制时的音色，新叠录可以使用另一种音色。当前 Loop 保存在应用数据目录。

## 四种乐器

Guitar：左摇杆选和弦，右摇杆上下扫弦；A、B、X、Y、L1、R1 从低音到高音分别拨六根弦，按下拨一次，可组合多根弦或弹奏分解和弦。L2 切换和弦组，R2 消音。六根弦显示对应按键、力度及实际音高，按键提示跟随 A/B、X/Y 交换设置。

Expressive：右摇杆选音，按住 L1 发声；左摇杆控制音色和揉音，右摇杆推离圆心的距离控制力度。设置可选择音阶轮或连续音高，也可选择摇杆直接发声。长笛与小提琴支持持续表现。

Keys：A、B、X、Y、L1、L2、R1、R2 对应八个音阶音，支持同时按键。左摇杆控制弯音与揉音。钢琴和电钢琴起音后自然衰减，松键产生释音。

Drum Machine：A 底鼓、B 军鼓、X 闭镲、Y 开镲、L1 拍手、L2 低通鼓、R1 高通鼓、R2 Crash。左摇杆上下调力度、左右调明亮度，闭镲切断开镲尾音。网格显示已录鼓点和播放列。

有音高的乐器共用方向键：上 / 下按住临时升 / 降八度，左按住临时升一个半音；右＋上 / 下调整固定八度。设置中可调整主音、调式、音量、音名 / 简谱和面键交换。

## 四轨 Loop

先按住右方向键，再按以下按键：

| 按键 | 操作 |
| --- | --- |
| A | 播放 / 暂停四轨 |
| B | 录制 / 取消等待 / 结束本轮 |
| X | 撤销当前轨道的上一轮；录制时取消本轮 |
| Y，按住一秒 | 清空当前轨道；松手取消，清空后可撤销 |
| L1 / R1 | 减慢 / 加快速度，长按连续调整 |
| L2 / R2 | 上一个 / 下一个音色 |

第一次录制有四拍预备拍；播放中录制从下一轮开始，一圈后自动结束。支持一或两小节。已有轨道上再次录制就是叠录；有音高的轨道支持四层，鼓机持续追加鼓点。设置可选择鼓机量化、全部量化或自由时序。

顶部显示速度、小节与拍号位置及高亮播放状态。例如 BAR 1/2 BEAT 3/4 表示两小节循环的第 1 小节、第 3 拍；暂停保留位置。预备拍、等待、首次录制和叠录分别显示。轨道卡片展示内容与层数；录制、取消、撤销及清空后短暂显示结果。按键名称持续高亮，功能文字体现可用性。

循环换轮时，尾音自然延续。调速或调整长度时会显示准备状态和目标值，准备完成后同步切换。退出时保存当前 Loop，重新打开后准备完成，再使用右＋A 播放。窗口恢复或手柄重连后，将摇杆回中并松开按键即可继续。

半音与八度修饰在每次起音时确定：可先按住修饰键再弹奏，也可在起音后 30 毫秒内补按修饰键，音高会直接切换；松开修饰键后，已有发声与延音保持原音高，新音使用当前音区。吉他每次扫弦的六根弦共用起扫时的修饰；Keys 每个按键独立确定音高，可组合不同音区的和弦。Expressive 从发声开始到松开 L1 或摇杆回中，保持起音时的八度与半音；摇杆继续控制旋律、弯音与揉音。
