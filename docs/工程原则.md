# 工程原则检查

- 当前界面直接说明乐器、音色、音乐位置与操作；文案使用正向表述。
- 界面展示演奏信息。缓存、线程和格式细节位于工程文档。
- 测试通过按键、声音和保存结果验证行为。键盘变调回归使用头 20 毫秒音频的目标周期一致性；音高回归覆盖迟按修饰键与松开恢复。
- 所有代码文件逐一计数，最大为 DaisySP 的 dsp.h，362 行。
- 音色身份、默认项及参数集中于 sound_catalog；产品名称与安装身份集中于 product.json；设置、界面和持久化引用同一目录。分拍、位置、按键映射与文件版本各有权威定义。
- 通用发声模型与音色数据分离，Keys 的离散音高规则与音色选择分别处理。新增同模型音色通过追加目录记录扩展，已有输入、界面与保存逻辑继续使用目录。
- 当前实现使用新录音文件及当前格式。源码提供当前读取器，构建与安装工具使用统一产品身份；录音、构建与安装均采用当前实现。
- 当前模式使用 Guitar、Expressive、Keys、Drum Machine；音色使用 SoundPreset / sound，轨道使用 track，录制一轮使用 take，容量使用 layer。上游组件名称与版权声明保留原名。
